# Volleyball Registration Form

Ein PyQt6-basiertes Registrierungsformular für Volleyball-Teilnehmer, das Daten als **CSV, JSON oder XML** speichern kann.

## Funktionen
- Eingabe von Name, Alter, Geschlecht, Zufriedenheit und Notizen
- Datenexport in CSV, JSON oder XML
- Einfache Benutzeroberfläche

## Voraussetzungen
- Python 3.x
- PyQt6 (`pip install -r requirements.txt`)
